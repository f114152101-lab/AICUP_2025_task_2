壹、資料處理與程式環境
一、資料前處理
本競賽的資料集特性為灰階圖片且偵測物件 (主動脈瓣) 非常小，這對傳統的 RGB 彩圖模型構成挑戰。為了優化 YOLOv8x 在此類數據上的表現，處理流程聚焦於通道調整、數據不平衡處理及圖像增強準備。
1.	灰階通道轉換:
由於輸入為單通道灰階影像，為使 YOLOv8x 預訓練在 RGB 三通道上的權重能被使用，我們採用了複製通道的方法。即將單一灰階通道複製三次，模擬 RGB 圖像的結構，但三個通道的像素值完全相同。這使得模型能夠載入並利用 ImageNet/COCO 預訓練權重，同時保持原始的灰階強度信息。
2.	數據不平衡處理:
原始數據集存在正負樣本不平衡（正樣本 2,787 張，負樣本 14,076 張，比例達1:5）。
在資料集分割階段，我們確保訓練集與驗證集保持相同的類別分佈（7:3 比例）。
訓練階段，我們採用了三階段訓練策略，在第二階段透過負樣本過採樣（1:2）來主動平衡類別，以強化模型抵抗背景雜訊與提升對小物體的敏感度。
3.	圖像增強準備:
o	增強準備： 考量到 CT 影像的幾何變異性 (如拍攝角度、病人姿勢)，我們在訓練參數中高度依賴幾何變形 (如旋轉、平移、縮放) 增強，而禁用了 HSV (色相、飽和度、亮度) 增強，因為灰階 CT 影像的強度資訊 (V 通道) 是診斷的關鍵，不應被隨機改變。

貳、模型設計與訓練策略
一、模型訓練原始程式碼與說明
訓練、驗證策略與核心程式碼邏輯：
核心邏輯在於實施三階段漸進式訓練，以精確處理類別不平衡和灰階小物體偵測的難題。

1.	階段一：
純淨特徵學習採用全部正樣本，使用 YOLOv8x.pt 初始化權重。目標是讓模型快速聚焦於主動脈瓣的微小形態特徵。
2.	階段二：
負樣本衝擊強化 (1:2) 載入階段一的最佳權重，並使用 1 倍正樣本與 2 倍負樣本組成的平衡數據集。這是為了在保持高召回率的基礎上，大幅降低誤報率，使模型學會區分背景與微小目標之間的邊界。
3.	階段三：
全數據集微調載入階段二的最佳權重，使用全部 16,863 張圖片進行最終微調。目的是在全數據集的真實分佈下，調整模型的泛化能力與最終性能。

參、分析與結論
一、模型成效與分析
1. 模型選用分析 (YOLOv8x)
選用 YOLOv8x 是基於對極小物體偵測與灰階圖像特性的考量。
	深層網絡結構的必要性： YOLOv8x 是 YOLO 系列中層次最深、參數量最大的模型。由於主動脈瓣在 CT 影像中佔據的像素面積極小，傳統淺層網絡難以提取足夠的判別特徵。更深的骨幹網絡 (Backbone) 提供了更大的感受野與更豐富的特徵層次，對於捕捉細微的邊緣和紋理至關重要。
	無錨點設計： YOLOv8 採用無錨點設計，避免了傳統 Anchor-based 模型在面對極端尺度變化的小物體時，需要手動或自動調整大量錨框參數的複雜性，使得小目標的定位更加靈活準確。
2. 訓練策略成效分析
三階段策略的價值：
	第一階段的純淨學習確保模型在沒有背景雜訊干擾下，高效收斂至目標特徵的局部最優解。
	第二階段的1:2 平衡是關鍵。在醫療影像和瑕疵檢測中，誤報的成本很高。通過有意識地引入兩倍數量的負樣本，並繼承已學會目標特徵的權重，模型能更有效地學習「什麼是背景/雜訊」，極大地提高了模型的特異性，最終結果為 mAP的穩定提升。
超參數影響：
	將 box 損失權重提高到 10.0，成功地將模型的關注點從整體分類轉向精確的邊界框定位。在小物體場景中，一個像素的定位差異就可能導致 IoU大幅下降，此調整確保了邊界框的準確性。
	禁用 HSV 增強（全部為 0）是正確的決策，維持了 CT 影像的原始灰階強度，保證了模型對真實醫學特徵的學習。
3. 開源資源影響分析
本專案的基礎（YOLOv8x）完全依賴於 開源的 Ultralytics 框架及其在 COCO 上的預訓練權重。

	正面影響： YOLOv8x.pt 提供了強大的遷移學習能力。若從零開始訓練，需耗費數週時間與數百萬張圖片。利用開源預訓練權重，我們能直接從高性能的通用特徵提取器開始，將訓練時間從數週縮短至數日。

	負面影響： 預訓練權重是在 RGB 圖像上訓練的，與 CT 灰階圖像存在領域差距。

	我們透過複製通道的方法來彌補這一差距，並通過三階段訓練中的前兩階段進行領域適應，使通用特徵轉化為醫學影像特徵。

二、未來可能改進方向
	專門的單通道骨幹網絡： 未來可嘗試修改 YOLOv8 的骨幹網絡，使其能夠直接處理單通道灰階輸入，避免通道複製帶來的潛在冗餘計算，並可能引入如 3D CNNs 來處理 CT 影像的立體連續性。

	更先進的數據採樣策略： 嘗試困難負樣本挖掘。在訓練過程中，主動識別那些容易被模型誤判為正樣本的負樣本（即困難負樣本），並在後續訓練中給予更高的權重，以進一步降低誤報率。
